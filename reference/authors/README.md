# Исходные файлы авторов

Здесь сохранены без изменений шесть Python-файлов, предоставленных вместе со
статьёй Wang и Lei, [Training a Minesweeper Agent Using a Convolutional Neural
Network](https://www.mdpi.com/2076-3417/15/5/2490) (2025).

Они служат материалом для изучения исходного подхода. Основная реализация проекта
находится в `../../Minesweeper AI solver.ipynb` и не импортирует эти файлы.

Эта копия исходников неполная: отсутствуют используемые авторами модули `lib.models`,
`lib.wrappers` и ресурсы интерфейса. В конце `minesweeper_train_cnn.py` также есть
вызов `os.system("shutdown")`. Для запуска проекта используйте основной ноутбук;
эти скрипты оставлены как исходный справочный материал.
