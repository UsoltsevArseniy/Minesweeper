# Minesweeper

Обучение CNN с учителем и DQN-агента для игры в сапёра; сравнение с двумя алгоритмическими стратегиями. Среда реализована на NumPy, нейросети на PyTorch. Основной эксперимент: поле 6×6, четыре мины, безопасный первый ход в левом верхнем углу.

## Результаты

Все четыре метода оценены на одних и тех же 2000 отложенных расстановках мин. Победа = открыты все безопасные клетки. Среднее число ходов включает первый клик и проигранные партии. Меньшее число ходов само по себе не означает лучшую игру.

- **CNN с учителем:** зафиксированный `checkpoints/latest.pt` после 2 млн кликов.
- **DQN:** обучение до 4 млн кликов; для теста выбран `best.pt` на шаге **3 950 121**
  по максимальной доле побед на валидации — **89,45% на 1024 партиях**.
  На тесте DQN играет без случайных исследовательских ходов (`epsilon=0`).

| Метод | Победы | Доля побед | 95% интервал Уилсона | Среднее число ходов |
| :--- | ---: | ---: | :--- | ---: |
| CNN  | 1851 / 2000 | 92,55% | [91,32%; 93,62%] | 8,08 |
| DQN | 1768 / 2000 | 88,40% | [86,92%; 89,73%] | 6,97 |
| SP | 1719 / 2000 | 85,95% | [84,36%; 87,40%] | 8,03 |
| CSP | 1912 / 2000 | 95,60% | [94,61%; 96,41%] | 8,97 |

DQN превзошёл SP на этом наборе, но уступил CNN с учителем и CSP.
После первого запуска до 2 млн кликов выбранный по валидации DQN давал
**83,35%** побед на тесте; после продолжения до 4 млн — **88,40%**.

## Обучение с учителем

1. Первый клик размещает мины равномерно среди остальных 35 клеток. При открытии нуля раскрывается вся связанная через восемь направлений область нулей вместе с числовой границей. Клик по числу больше нуля открывает одну клетку.
2. Если после клика игрок не проиграл и партия ещё продолжается, сохраняется обучающий пример из двух частей: видимое состояние доски (вход сети) и вектор из 36 правильных ответов — `1` там, где есть мина, `0` там, где её нет. Правильные ответы берутся из внутренней карты игрового движка и используются для вычисления ошибки при обучении. На вход сети эта карта не подаётся. Одна партия может дать несколько примеров: видимая доска меняется, карта мин нет.
3. Вход CNN для одной доски имеет форму `[2, 6, 6]`: открытые числа, делённые на 8, и отдельная маска закрытых клеток. Маска отличает открытый ноль от закрытой клетки.
4. Для каждой доски CNN выдаёт 36 логитов — по одному числу на клетку. Сигмоида превращает их в оценки вероятности мины. Во время игры сеть обрабатывает текущую доску и выбирает закрытую клетку с минимальным логитом: у неё также минимальная предсказанная вероятность мины.
5. Когда накоплены 320 примеров, они перемешиваются и подаются на обучение мини-батчами по 32. Форма входа — `[32, 2, 6, 6]`. Для каждой закрытой клетки каждой доски вычисляется бинарная кросс-энтропия (BCE) между прогнозом сети и правильным ответом. Ошибки суммируются и делятся на общее число закрытых клеток во всех 32 досках. Открытые клетки в ошибку не входят. После каждого мини-батча Adam обновляет веса. По всем 320 примерам выполняются 10 проходов (эпох), затем буфер очищается: всего 100 обновлений, learning rate = `1e-5`. Новые состояния собираются уже обновлённой моделью.

`env_steps` — клики, `episodes` — партии, `update_rounds` — обученные порции,
`optimizer_steps` — обновления весов. В сохранённом запуске: 272904 партии,
5397 порций и 539700 обновлений весов. Партия не считается эпохой.

Архитектура:

```text
[2, 6, 6]
→ Conv(2→64, 3×3, padding=1) + ReLU
→ Conv(64→64, 3×3, padding=1) + ReLU
→ Conv(64→64, 3×3, padding=1) + ReLU
→ Flatten → Linear(2304→256) + ReLU
→ Linear(256→256) + ReLU → Linear(256→36)
```

Всего 740196 параметров, dropout отсутствует. Размер выхода привязан к размеру
поля. Преимущество этой архитектуры перед меньшими сетями пока не проверялось.

## Обучение с подкреплением: DQN

Вход состоит из десяти каналов: отдельный канал для каждого открытого числа от 0 до 8
и для закрытых клеток. Сеть использует те же размеры свёрточных и полносвязных
слоёв, что и CNN выше, с 10 входными каналами вместо 2. Выход состоит 36 оценок Q,
то есть ожидаемой суммы дисконтированных наград для каждого действия.
Открытые клетки исключаются из выбора; агент выбирает максимальное Q среди закрытых.

- В replay сохраняются переходы `(состояние, действие, награда, следующее состояние, конец партии)`.
- Обычный DQN: цель для нетерминального перехода — `r + 0.9 * max Q_target(s', a')`,
  для терминального — `r`. Ошибка MSE; target network копируется каждые 2000 обновлений.
- Награды: `+36` за победу, `−36` за мину, `+1` за безопасный нетерминальный ход
  рядом с открытой клеткой, иначе `−0.5`. Скрытая карта мин не подаётся сети.
- При обучении используется epsilon-greedy: после разогрева epsilon снижается
  с 1 до 0,05 за 1 млн решений агента. Обязательный безопасный первый клик
  входит в `env_steps`, но не считается решением агента и не попадает в replay.
- Adam начинает с `learning_rate=1e-4`; каждые 500 000 обновлений весов ставка
  уменьшается вдвое до минимума `1e-5`. Норма градиента ограничена значением 10.
- Checkpoints сохраняют основную и target-сеть, Adam, replay, счётчики и состояния
  генераторов случайных чисел; это позволяет продолжать обучение после остановки.

В завершённом запуске: 4 000 000 кликов, 688 739 партий и 3 301 262 обновления весов.
Обучение проходило неравномерно: после раннего провала доля побед на валидации
восстановилась и к концу достигла 89,26%; лучший checkpoint дал 89,45%.

## Разделение данных и baselines

С безопасной первой клеткой возможны C(35, 4) = 52360 расстановок. Для CNN с учителем при `seed=42` функция `make_holdout_layouts` выделяет 256 уникальных позиций для валидации и 2000 для теста. Обучающий генератор исключает обе группы; ему доступны 50104 расстановки. Позиции и состояния могут повторяться. Два миллиона кликов не означают два миллиона уникальных полей. Совпадения частичных наблюдений и симметрии между частями не исключены.

Для DQN валидация расширена до 1024 уникальных расстановок, а тестовые 2000 сохранены теми же. Генератор обучения DQN исключает обе группы; остаются 49336 доступных расстановок. Валидация проводится примерно каждые 25000 кликов после завершения текущей партии.

- **SP (Single Point):** повторяет логические выводы из отдельных открытых чисел. Если безопасных клеток не найдено, выбирает минимальную локальную оценку риска; при нескольких соседних числах берёт максимум оценок. Для остальных клеток используется остаточная плотность мин.
- **CSP:** перечисляет все 52360 расстановок и оставляет согласующиеся с наблюдаемыми числами. Доля вариантов с миной в клетке даёт её точную вероятность при равномерном априорном распределении. Затем выбирается клетка с минимальным риском.

Оба алгоритма знают размеры поля и общее число мин, но получают только видимую доску. При равном риске выбирается наименьший индекс. Это конкретные реализации SP/CSP; совпадение их правил догадки с реализациями из статьи не заявляется.
CSP минимизирует риск ближайшего хода. Он не планирует всю партию, поэтому его результат не является доказанной верхней границей качества. Полный перебор пригоден для малого поля; в ноутбуке установлен предел в миллион расстановок, чтобы случайно не создавать неподъёмный массив при смене размера
