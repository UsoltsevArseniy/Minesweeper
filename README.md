# Minesweeper

Обучение CNN с учителем на состояниях из собственных партий в сапёра и сравнение
с двумя алгоритмическими стратегиями. Среда реализована на NumPy, модель на
PyTorch. Основной эксперимент: поле 6×6, четыре мины, безопасный первый ход
в левом верхнем углу.

## Результаты

Повторная оценка сохранённого `latest.pt` после 2000000 кликов на одних и тех же
2000 отложенных позициях. Победа = открыты все безопасные клетки. Среднее число
ходов включает первый клик и проигранные партии.

| Метод | Победы | Доля побед | 95% интервал Уилсона | Среднее число ходов |
| :--- | ---: | ---: | :--- | ---: |
| CNN | 1851 / 2000 | **92,55%** | [91,32%; 93,62%] | 8,08 |
| SP | 1719 / 2000 | 85,95% | [84,36%; 87,40%] | 8,03 |
| CSP | 1912 / 2000 | 95,60% | [94,61%; 96,41%] | 8,97 |

Парные разности на общих позициях:

- CNN − SP: **+6,60 п.п.**, приближённый 95% интервал [+4,77; +8,43] п.п.
- CNN − CSP: **−3,05 п.п.**, приближённый 95% интервал [−4,44; −1,66] п.п.

## Как устроено обучение

1. Первый клик размещает мины равномерно среди остальных 35 клеток. При открытии нуля раскрывается вся связанная через восемь направлений область нулей вместе с числовой границей. Клик по числу больше нуля открывает одну клетку.
2. Если после клика игрок не проиграл и партия ещё продолжается, сохраняется обучающий пример из двух частей: видимое состояние доски (вход сети) и вектор из 36 правильных ответов — `1` там, где есть мина, `0` там, где её нет. Правильные ответы берутся из внутренней карты игрового движка и используются для вычисления ошибки при обучении. На вход сети эта карта не подаётся. Одна партия может дать несколько примеров: видимая доска меняется, карта мин нет.
3. Вход CNN для одной доски имеет форму `[2, 6, 6]`: открытые числа, делённые на 8, и отдельная маска закрытых клеток. Маска отличает открытый ноль от закрытой клетки.
4. Для каждой доски CNN выдаёт 36 логитов — по одному числу на клетку. Сигмоида превращает их в оценки вероятности мины. Во время игры сеть обрабатывает текущую доску и выбирает закрытую клетку с минимальным логитом: у неё также минимальная предсказанная вероятность мины.
5. Когда накоплены 320 примеров, они перемешиваются и подаются на обучение мини-батчами по 32. Форма входа — `[32, 2, 6, 6]`. Для каждой закрытой клетки каждой доски вычисляется бинарная кросс-энтропия (BCE) между прогнозом сети и правильным ответом. Ошибки суммируются и делятся на общее число закрытых клеток во всех 32 досках. Открытые клетки в ошибку не входят. После каждого мини-батча Adam обновляет веса. По всем 320 примерам выполняются 10 проходов (эпох), затем буфер очищается: всего 100 обновлений, learning rate = `1e-5`. Новые состояния собираются уже обновлённой моделью.

`env_steps` — клики, `episodes` — партии, `update_rounds` — обученные порции,
`optimizer_steps` — обновления весов. В сохранённом запуске: 272904 партии,
5397 порций и 539700 обновлений весов. Партия не считается эпохой.

Архитектура:

```te
[2, 6, 6]
→ Conv(2→64, 3×3, padding=1) + ReLU
→ Conv(64→64, 3×3, padding=1) + ReLU
→ Conv(64→64, 3×3, padding=1) + ReLU
→ Flatten → Linear(2304→256) + ReLU
→ Linear(256→256) + ReLU → Linear(256→36)
```

Всего 740196 параметров, dropout отсутствует. Размер выхода привязан к размеру
поля. Преимущество этой архитектуры перед меньшими сетями пока не проверялось.

## Разделение данных и baselines

С безопасной первой клеткой возможны `C(35, 4) = 52360` расстановок. При `seed=42` функция `make_holdout_layouts` выделяет 256 уникальных позиций для валидации и 2000 для теста. Обучающий генератор исключает обе группы; ему доступны 50104 расстановки. Позиции и состояния могут повторяться. Два миллиона кликов не означают два миллиона уникальных полей. Совпадения частичных наблюдений и симметрии между частями не исключены.

- **SP (Single Point):** повторяет логические выводы из отдельных открытых чисел. Если безопасных клеток не найдено, выбирает минимальную локальную оценку риска; при нескольких соседних числах берёт максимум оценок. Для остальных клеток используется остаточная плотность мин.
- **CSP:** перечисляет все 52360 расстановок и оставляет согласующиеся с наблюдаемыми числами. Доля вариантов с миной в клетке даёт её точную вероятность при равномерном априорном распределении. Затем выбирается клетка с минимальным риском. Разделение train/validation/test решателю не передаётся.

Оба алгоритма знают размеры поля и общее число мин, но получают только видимую доску. При равном риске выбирается наименьший индекс. Это конкретные реализации SP/CSP; совпадение их правил догадки с реализациями из статьи не заявляется.

CSP минимизирует риск ближайшего хода. Он не планирует всю партию, поэтому его результат не является доказанной верхней границей качества. Полный перебор пригоден для малого поля; в ноутбуке установлен предел в миллион расстановок, чтобы случайно не создавать неподъёмный массив при смене размера.

## Разбор ошибок CNN

Вероятности CSP вычисляются вдоль траекторий CNN только для диагностики и не влияют на её решения. На 14160 ходах после первого:

- 550 раз CNN выбирала клетку с риском выше минимального;
- 287 раз рисковала при наличии гарантированно безопасной клетки;
- 34 из 149 поражений произошли при наличии безопасного хода;
- в 8 из этих 34 случаев CNN выбрала гарантированную мину.
